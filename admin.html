Masuk Panel Admin

Hubungkan dengan akun GitHub Anda untuk mengelola konten berita.

Token disimpan aman hanya di browser lokal komputer Anda.

Bagaimana Cara Mendapatkan Token GitHub?

  1. Buka akun GitHub Anda.
  2. Pergi ke Settings > Developer Settings > Personal Access Tokens > Tokens (classic).
  3. Klik Generate new token (classic), beri nama "Web Admin", centang opsi repo (sangat penting agar bisa menulis data), lalu klik Generate.
  4. Salin token yang muncul dan tempelkan di formulir di atas.
